## 미검증·제한

- OpenAI, TourAPI, Supabase: 자격 증명이 없어 실제 호출·실제 DB 반영은 미검증.
- 공개 Open-Meteo에 실제 요청했으나 TLS 연결 중 WinError 10054로 연결이 종료되었습니다. 이를 성공으로 표시하지 않았고 TLS 검증 해제나 더미 값 대체를 하지 않았습니다.
- DB 없는 시연·모의 어댑터 시험은 통과했지만 실제 복합 API의 정상·오류·성찰 전후 시험은 추가로 필요합니다.
- SQLite 체크포인터·선호, JSON 데모 저장소는 단일 프로세스 기준입니다. 다중 worker·분산 잠금·운영 보존 정책은 미구현.
- 비용·이동시간·실내 여부가 없는 축제는 확인할 수 없는 사실을 확정하지 않습니다. 실제 모델의 할루시네이션 품질·토큰·비용·지연은 측정하지 않았습니다.
- 프론트 연결, 실제 인증, 이벤트 자동 실행, 배포는 별도 작업입니다.
